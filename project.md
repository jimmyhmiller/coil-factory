# coil-factory

## Summary

Run software factories — Markdown recipes of agent stations — on this machine,
other machines, or sandboxes, and watch and talk to every agent from one place.
Written entirely in Coil. The `factory` app is at the repository root
([README](README.md), [design](DESIGN.md)); the reusable libraries it is built
from are in [libraries/](libraries/README.md).

Moved here from coil-agent-harness (branch `factory-platform`) on 2026-09-27.
